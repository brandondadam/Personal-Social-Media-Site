# Personal Social Media Site

A personal blog with a Twitter-style personal feed, built with [11ty (Eleventy)](https://www.11ty.dev/).

## Getting started

Install dependencies:

```bash
npm install
```

Run the dev server:

```bash
npm start
```

Build the static site:

```bash
npm run build
```

## Project structure

- `src/posts/` — blog posts (Markdown)
- `src/_includes/` — Nunjucks layouts and partials
- `src/_data/` — global data files
- `src/assets/` — styles, scripts, images, fonts
- `.eleventy.js` — Eleventy configuration
