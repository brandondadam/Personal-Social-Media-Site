The tools I actually reach for every day — not the ones I thought I'd be using when I set up my machine six months ago.

## Editor: VS Code (still)

I keep trying to switch to Zed or Neovim. I get three days in, hit some edge case with a language server or a missing extension, and come back. VS Code is boring and I mean that as a compliment. It just works.

The extensions I can't live without: **ESLint**, **Prettier**, and **GitLens** for the inline blame that tells me which past version of me wrote this disaster.

## Terminal: Ghostty

![The current state of my desktop — Ghostty on the left, VS Code on the right, nothing on the menu bar I don't understand](https://images.unsplash.com/photo-1537432376769-00f5c2f4c8d2?w=800&q=80&auto=format&fit=crop)

Switched from iTerm2 about three months ago and haven't looked back. It's fast in a way that's hard to articulate until you use it — scrolling through long build logs doesn't stutter, rendering feels immediate. The config is a single text file. It's exactly as complex as it needs to be.

## Version control: Git + lazygit

I know git on the command line well enough to not get into trouble. But `lazygit` in the terminal means I never have to type `git add -p` manually again. The interactive staging UI is genuinely excellent.

## HTTP client: Bruno

Moved from Postman to [Bruno](https://www.usebruno.com/) because Bruno stores collections as plain files in your repo. No cloud sync required, no account needed, and your API tests live next to the code they test. That's how it should have always worked.

## Note-taking: Obsidian

Daily notes for capturing stuff as it happens. A single vault synced with iCloud. I don't use any fancy plugins or elaborate systems — just markdown files and the search box. The graph view is fun to look at and I've never actually used it for anything.

## What I stopped using

- **Figma comments for dev handoff** — we moved to writing specs in markdown next to the code
- **npm scripts for everything** — reached for `make` for complex build pipelines and it's been fine
- **Linear integrations that auto-close PRs** — too many false closes on partial work

What tools are you using that I should try? Replies open.
