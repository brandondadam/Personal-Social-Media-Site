Not a book review column. Just a list of things I've read recently and whether they were worth it.

## The Timeless Way of Building — Christopher Alexander

Dense. Slow. Worth it. Alexander is writing about architecture but the underlying ideas about how good systems emerge from human needs rather than top-down design apply to almost everything. I kept thinking about software and UI design throughout. The Pattern Language is more famous but I'd start here because it explains why the patterns matter.

## Working in Public — Nadia Eghbal

Short and clear. About the economics and sociology of open source software — who maintains it, why, and how the relationship between maintainers and users has changed as GitHub lowered the friction for contributions. Made me think differently about the open source tools I use every day.

## Shop Class as Soulcraft — Matthew Crawford

An argument for working with your hands, written by someone who has a PhD in philosophy and runs a motorcycle repair shop. Some of it is a bit precious but the core point — that manual skill is undervalued and that direct engagement with the physical world has something to offer that knowledge work doesn't — is well made. Timely for me given the garage project.

## Currently reading

*The Soul of a New Machine* by Tracy Kidder. A 1981 book about building a minicomputer at Data General. It reads like a thriller. Highly recommended if you work in tech and have never read it.
